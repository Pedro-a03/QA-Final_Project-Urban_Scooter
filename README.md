# QA Final Project — Urban Scooter

End-to-end QA capstone project covering web, mobile, API, and database testing for the Urban Scooter delivery platform.

## Scope

- **Task 1:** Testing theory (equivalence partitioning, BVA, SQL, test design)
- **Task 2:** Web application — checklist (50+ items) and data validation (BVA across 8 fields)
- **Task 3:** Mobile application — 31 test cases (push notifications, offline behavior)
- **Task 4:** REST API — checklist across 4 endpoints with PostgreSQL verification

## Results

- 48 bugs identified and documented in Jira (BUG-001 to BUG-048)
- Cross-browser testing: Firefox, Microsoft Edge (1920x1080)
- Mobile testing: Android Studio Emulator (Android 9.0, API 28)
- API testing: Postman + direct database verification (psql)
